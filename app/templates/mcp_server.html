MCP-Server für Obi

{% if not is_admin %}

MCP-Server verwalten kann nur ein Administrator. Ihre eigenen Anmeldungen finden Sie unter Obi-Verbindungen.

{% else %}

Über MCP-Server greift Obi im KI-Chat auf andere Systeme des Unternehmens zu – etwa die Belegablage eines anderen Herstellers, ein CRM oder eine Wissensdatenbank. Die Werkzeuge erscheinen im Chat als präfix__werkzeug. Lesende Werkzeuge laufen sofort, alle anderen erst nach Bestätigung im Chat; Ergebnisse gelten als Fremddaten.

Zentraler Zugang: Der Administrator meldet sich einmal an, alle Benutzer arbeiten mit diesem Zugang. Je Benutzer: Jeder meldet sich unter Obi-Verbindungen selbst an; Obi arbeitet im fremden System dann mit dessen Rechten. Tokens und Secrets werden verschlüsselt gespeichert und nie wieder angezeigt.

Redirect-URI für OAuth-Clients: {{ redirect_uri }} – nur nötig, wenn der Anbieter keine automatische Client-Registrierung anbietet und Sie eine Client-ID eintragen.
